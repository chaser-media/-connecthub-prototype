# ConnectHub PWA — Envato conversion V1

Base: DatingKit Bootstrap + PWA template.

## Start
Open `index.html` or serve this folder with a static web server. The root redirects to `connecthub/onboarding.html`.

## Included ConnectHub flow
Onboarding → Phone Login → OTP → Profile setup → Discover/Search → Profile → Connection Credits → Payment demo → Unlock Conversation → Chat.

Additional prototype screens: Verification, Notifications, Report/Block, Settings, Admin Dashboard.

## Important
This is still a frontend/PWA prototype. OTP, verification, payment, chat persistence, database, admin authentication and moderation backend are not connected to production services. Connection Credits represent platform access to unlock a conversation; they are not payment to another user.
